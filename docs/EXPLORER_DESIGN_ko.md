# 탐색 화면 사용 안내

NutriOmics의 기본 화면은 한국어로 제공됩니다. 음식·성분·유전자·중재를 검색하고, 관련 연구의 조건과 원본 결과를 확인합니다.

| 화면 | 사용 방법 |
|---|---|
| 왼쪽 검색 | 이름·별칭·원본 식별자를 입력하고 목록에서 항목을 선택합니다. 검색어를 바꾸면 이전 선택과 결과를 해제합니다. |
| 근거 비교 | 연구·노출·대비·조직·대상자 범위를 확인합니다. 같은 연구의 여러 시료를 독립 대상자로 합산하지 않습니다. |
| 조건 설정 | 음식은 섭취량을 바로 입력합니다. 조직·반응 시간·반복 기간·섭취 빈도는 ‘조건 설정’을 펼쳐 입력합니다. 미입력 값은 미확인입니다. |
| 오른쪽 상세 | 현재 입력과 실제 연구를 조건별로 비교합니다. ‘일치·차이 있음·미확인’은 조건 대응이고 효능 판정이 아닙니다. |
| 발현·DNAm | 원본 측정 ID·대비·효과 단위·P/FDR을 확인합니다. 분석 버전과 원본 필드는 펼쳐 볼 수 있습니다. |
| 연결망 | 중심 배치·유형별 배치·자유 배치를 선택할 수 있습니다. 노드를 선택하면 관련 관계를 강조하고 원본 출처를 조회합니다. |
| 임상지표 | 지표별 항목을 펼쳐 대상자 범위·보고값·통계·원문 위치를 확인합니다. 전체 기록에는 원래 필드를 보존합니다. |

화면의 색은 항목 종류와 선택 상태를 구분합니다. 발현이나 메틸화 변화의 건강상 이득·손해를 판정하는 색이 아닙니다. 계산 예측과 자동 문헌 후보는 사용자가 선택한 경우에만 기본 근거와 함께 표시합니다.

화면 배치는 원본 식별자·분석 키·용량·통계값을 변경하지 않습니다. 임상 요약의 간단한 표시와 별도로 원문 보고값·비교 범위·전체 JSON을 열람할 수 있습니다. 원문 대조와 전문가 검수는 별도 상태입니다.

## 개발·검증

`frontend/explorer/src/research.css`가 기본 작업 화면의 시각 체계를 정의합니다. `ReferenceInputs`와 `Conditions`는 조건 입력·비교를, `ClinicalFacts`는 임상 보고값 표시를 담당합니다. `focusPositions`는 선택 항목을 중심으로 한 기하학적 배치이며 인과 순서를 뜻하지 않습니다.

```bash
cd frontend/explorer
pnpm build
node scripts/run-portable-tests.mjs
```

코드 검사는 실제 브라우저·운영 자료 검증을 대신하지 않습니다. 검증 기록은 코드 버전·자료 release·실행 환경을 함께 확인해야 합니다.
