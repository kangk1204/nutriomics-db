# NutriOmics network workbench

2026-10-09 네트워크 UI 개정. 데이터 release는 `explorer-20261009-v7`을 유지한다.

## 탐색

- 음식·성분·유전자·건강 항목을 검색하고 **연결망**을 선택한다.
- **경로 탐색**은 선택한 후보 경로와 하나의 주변 분기를 표시한다. 오른쪽 목록에서 다른 경로를 선택할 수 있다. 이 목록은 화면에 수신된 자료에서 구성한 경로이며 임상 근거 순위가 아니다.
- **인접 관계**는 중심 항목의 가까운 실제 연결을, **전체 연결**은 현재 수신한 제한된 그래프를 표시한다. 확장은 API의 250 노드·750 관계 상한을 따른다. 생략 수는 조회 중 만난 관계의 하한이다.
- 노드를 선택해도 화면과 중심 항목은 유지된다. **이 노드를 중심으로 탐색**을 눌렀을 때 새 그래프를 요청한다.
- 관계선 또는 **노드·관계 목록**의 행을 선택하면 원본 관계, 연구 조건, source ID·버전·PMID를 확인할 수 있다. 목록과 경로 버튼은 키보드로 조작할 수 있다.
- 표시된 노드 검색, 확대·축소, 화면 맞춤, 위치 고정, 확대 작업공간을 사용할 수 있다. 확대한 작업공간은 Escape로 닫을 수 있다.

## 과학적 표시

영양성분과 화합물의 같은 이름은 별도 노드로 유지한다. 정확히 동일한 양끝·관계 종류·tier·종·검수 상태·원본 맥락을 가진 기록만 표시 묶음으로 합친다. 개별 ID와 원본 기록은 보존한다. PMID는 중복을 제거하지만 독립 연구 수로 표시하지 않는다.

실선은 출처 수록 관계, 파선은 간접·후보·예측, 점선은 자동 추출 후보다. 실선이나 색은 인과성·임상 효능·건강상 이득을 뜻하지 않는다. 관계 필터로 경로의 구성 관계가 제외되면 완전한 경로 표시도 해제된다. 관계의 숫자에 단위가 없으면 단위 미확인으로 표시한다. 미측정·0·원본 100mL 기준도 유지한다.

## 독립 HTML

그래프의 저장 버튼은 **표시된 노드·관계**를 HTML로 내보낸다. 상단 내보내기는 현재 수신한 그래프 전체의 HTML·CSV·JSON을 제공한다. 서버에서 기존 source별 export 정책을 적용한다. 이용조건에 따라 상세를 넣을 수 없는 관계는 출처 링크와 제한 이유로 바꾼다. 따라서 공개 가능한 snapshot에 원래 후보 경로가 남지 않을 수 있다.

HTML은 JS·CSS·데이터를 내장하며 `connect-src 'none'` 정책을 사용한다. 처음 연결망을 열면 저장한 전체 snapshot을 보여준다. 온라인 DB의 추가 자료를 가져오거나 독립 HTML에서 식사 계산을 실행하지 않는다. 저장한 위치와 release ID를 함께 보존한다.

## 실행·검증

기존 프로젝트의 Python·프런트엔드 실행 환경을 사용한다. `frontend/explorer`에서 타입 검사 및 `npm run build`를 수행한다. 새 순수 함수 검증은 `node scripts/test-network-model.mjs`로 실행한다. 기존 transport·reading order·evidence conditions·meal presentation 검증도 유지한다. 네트워크 API의 전체 JSON 대신 ID·관계·tier를 먼저 정렬하는 최적화는 원본 선택·순서를 바꾸지 않는다.

참조: [Cytoscape.js](https://js.cytoscape.org/), [Reactome analysis user guide](https://reactome.org/userguide/analysis). 유형별 배치·후보 경로 비교·상세 선택 분리는 본 플랫폼의 설계 선택이다. 생물학적 예측 성능 또는 다른 플랫폼 대비 SOTA 성능을 검증했다는 의미가 아니다.
