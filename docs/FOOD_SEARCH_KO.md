# 한글 식품 검색명

현재 추가한 검색명은 김치, 요구르트, 요거트다. 전체 식품을 번역한 목록은 아니다.

| 입력 | 찾는 범위 | 주의할 점 |
|---|---|---|
| 김치 | USDA-FDC:2710077, 원본 이름 Kimchi | 식품 코드와 원본 이름이 모두 일치할 때만 연결한다. 배추김치, 김치찌개 등 세부 종류를 추정하지 않는다. |
| 요구르트·요거트 | 원본 식품명에 Yogurt가 있는 음식 기록 | 향미·지방 함량·혼합 제품을 각각 표시한다. 같은 식품이나 시험 제품이라는 의미가 아니다. |

`nutrigenomics/food_search_aliases.py`에서 검색명과 버전을 관리한다. 원본 DB와 성분 값은 변경하지 않는다. API의 `search_context`는 검색용 연결이며 전문가 검수 상태와 별개다. 화면에는 원본 식품명을 그대로 표시한다.

검색명을 추가할 때는 원본 ID·이름·출처를 확인하고, 기록별 대응과 넓은 종류 검색을 구분한다. 버전과 해시가 캐시 키에 들어가므로 새 코드로 서비스 프로세스를 시작하면 이전 검색 캐시를 재사용하지 않는다. 원본 식품 코드가 같아도 이름이 바뀌면 김치 대응은 적용되지 않는다.

검증 명령:

```text
python -m pytest tests/test_food_search_aliases.py tests/test_explorer_api.py tests/test_explorer_performance.py -q
```

독립 HTML은 내장된 원본 이름·별칭을 검색한다. 이 서버용 한글 검색명 표를 HTML에 추가했다는 뜻은 아니다.
