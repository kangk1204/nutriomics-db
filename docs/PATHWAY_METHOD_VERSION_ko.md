# GSE56960 경로 결과의 버전과 검수

같은 정확한 입력으로 다시 실행할 수 있는 경로판을 별도로 제공합니다. 과거
값은 보존합니다. 과거 실행의 정확한 moderated-t·난수 상태는 남아 있지 않아
당시 값을 완전히 복구했다는 주장은 하지 않습니다.

기술 확인과 과학적 수록 판정은 구분합니다. 사람 판정은 자동으로 만들지
않습니다. 이 판은 내부 검수용이며 논문 공개판이 아닙니다.

## 조회

기존 `/api/v1/explorer/omics/results`의 URL과 기본 조회는 유지합니다.
GSE56960의 `feature_type=pathway`에만 선택 인자
`pathway_selection=corrected_if_available`를 추가하면 새 판을 조회합니다.
화면의 GSE56960 경로 조회는 이 인자를 사용하며, 실제 행에 새 분석 버전과
사람 검수 대기 상태를 표시합니다. 유전자·메틸화 결과를 교체하지 않습니다.

운영자는 프로젝트 환경에 다음 값을 설정합니다.

- `NUTRIOMICS_CORRECTION_ACCESS=internal_review`
- `NUTRIOMICS_PATHWAY_SELECTION`: 검증된 selector JSON
- `NUTRIOMICS_PATHWAY_SELECTION_SHA256`: 해당 파일의 SHA256
- `NUTRIOMICS_PATHWAY_ARTIFACT_ROOT`: 해당 Parquet 디렉터리

파일·해시·부모 분석 키가 달라지면 조회를 중단합니다. 실패를 0건이나 과거
판으로 대신 표시하지 않습니다. Cursor는 release·교정판·조회 조건에 묶입니다.
원래 API 인자만 보내는 외부 코드는 과거 판을 계속 읽으므로, 분석 버전을
논문과 함께 기록해야 합니다.

## 통계와 집계

- 식전 대비 18개: 30,330개 경로×대비 행입니다.
- 열량 조건의 변화 차이 12개: 20,220개 경로×대비 행입니다.
- 두 실행은 각각 새 분석 버전입니다. 50,550행을 추가 대상자나 독립 연구로
  합산하지 않습니다. 원래 14개 모델 실행과 경로 출력 버전 수는 다릅니다.
- 대비 내 FDR와 분석 전체 FDR를 따로 보존합니다. 주 FDR의 범위는 원래
  분석별 정책을 유지합니다. 사전 등록된 확증 검정이라고 표현하지 않습니다.
- NES의 SE는 결측입니다. `fgsea_log2err`를 NES SE나 건강효과의 불확실성으로
  바꾸지 않습니다. 결측·비유의·음의 방향도 보존합니다.
- 과거 값과 비교해 FDR 0.05 여부가 달라진 두 경로를 비교표에 남깁니다.

## 원본 특징 이름과 화면 표시

API는 원래 다섯 부분 분석 키와 수치를 유지하면서 별도 표시 분류를 추가합니다.
`cpg`는 메틸화 probe로, `dmr`는 영역 검정으로 표시합니다. cg/ch 접두사만으로
화학적 CG/CH 맥락을 확정하지 않으며, 영역 검정을 발견·검증된 DMR로 부르지
않습니다. 이 표시는 전문가 승인이나 생물학적 효능 판정이 아닙니다.
