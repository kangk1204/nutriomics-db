# 검토 안내

[프로젝트 소개](../README.md) · [English](REVIEWER_GUIDE.md) · [설치 방법](GETTING_STARTED.ko.md)

## 어떤 연구 도구인가요?

NutriOmics는 식품 성분과 사람 식이중재 연구의 결과를 함께 조회하는 DB입니다.
식품의 성분량을 계산하고, 관련 연구의 섭취 조건과 유전자 발현·DNA 메틸화 결과를 확인할 수 있습니다.
각 결과에는 출처와 분석 버전을 남깁니다.

연구자가 관련 실험을 찾아 검토하는 용도입니다. 개인의 유전자 변화량이나 질병 위험을 예측하는
모델의 완성을 뜻하지는 않습니다.

## 어떤 순서로 보면 되나요?

1. [프로젝트 소개](../README.md)에서 목적과 사용 예를 확인합니다.
2. 아래 표와 [기준 자료](reference-data-summary.json)에서 구축 규모와 현재 상태를 확인합니다.
3. [자료 사전](PUBLIC_DATA_DICTIONARY.md)에서 식품·연구·분석 결과의 정의를 확인합니다.
4. [설치 방법](GETTING_STARTED.ko.md)의 작은 검사부터 실행합니다. 전체 데이터 없이도 가능합니다.
5. 필요하면 [원본 수집·재분석 방법](WORKBENCH_PUBLIC_REBUILD_ko.md)을 살펴봅니다.

## 현재 어디까지 진행됐나요?

2026년 10월 24일 점검한 공개 후보 구성요소를 기준으로 합니다. 진행 중인 추가 분석은 아래 수치에 포함하지 않습니다.

| 항목 | 현재 상태 |
|---|---|
| 식품 자료 | 식품 기록 5,794개, 성분 기록 368,208건 |
| 사람 연구 | 등록 9개, 재분석 자료가 있는 연구 묶음 8개 |
| 오믹스 결과 | 14개 분석 실행, 정량 결과 6,254,477행 |
| 코드 | 수집·분석·DB 구축·갱신·조회 코드 공개 |
| 과학적 검수 | 핵심 기록 263개와 새 경로 출력 2개의 사람 판정 대기 |
| 최종 조회 평가 | 검수한 정답과 최종 데이터 버전 확정 후 실시 |
| 데이터 공개 등록 | 전체 다운로드와 DOI 등록 준비 중 |
| 웹 공개 | 외부 공개 HTTPS 서비스 준비 중 |
| 추가 개발 | DIRECT PLUS 확장 QC·민감도 검증, 별도 브랜치의 문헌·모델 통합 진행 중 |

정량 결과의 행 수는 유전자·측정 위치·비교 조건·분석 버전별 값의 수입니다.
같은 사람을 여러 번 측정하거나 같은 자료를 다시 분석한 결과도 포함하므로 대상자 수로 읽으면 안 됩니다.

## 연결망을 어떻게 해석하나요?

| 기록 | 의미 |
|---|---|
| 식품 성분 | 원자료에 기재된 음식의 함량과 측정 기준 |
| 사람 중재 결과 | 해당 용량·기간·조직·비교 조건에서 관찰한 값 |
| 계산 예측 | 조절영역과 유전자 등의 관계를 계산한 결과 |
| 자동 문헌 후보 | 프로그램이 문헌에서 추출한 관계 후보 |

연결선을 따라 여러 기록을 찾을 수 있습니다. 서로 다른 연구의 연결을 이어 보았다고 해서
음식이 건강 변화를 일으키는 과정이 입증되는 것은 아닙니다.
GraphRegLR 예측 1,073,409건은 식품의 효능을 실험한 건수가 아닙니다.

## 검사는 무엇을 확인하나요?

코드 검사는 성분 계산, 결과 값 보존, 출처 연결, API 응답과 데이터 버전 처리를 확인합니다.
이 검사를 통과하는 것과 원 논문의 해석이 타당하다는 사람의 판정은 별개입니다.
프로젝트는 두 상태를 구분해 기록합니다.

현재 저장소에는 전체 DB와 원자료가 포함돼 있지 않습니다. 코드를 내려받아 검사하거나 화면을
빌드할 수 있으며, 전체 자료를 재구축하려면 원본 파일과 해당 이용조건을 따로 확인해야 합니다.
자세한 절차는 [운영 방법](PUBLICATION_RUNBOOK_ko.md)에 있습니다.

[DB 구조와 쉬운 설명](DB_STRUCTURE.ko.md), [보고서용 그림](figures/db-structure/README.md), [이번 코드의 변경·검사 범위](UPDATES_20261024.ko.md)를 함께 볼 수 있습니다.
