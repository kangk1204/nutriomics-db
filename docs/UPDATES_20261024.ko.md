경로 교정의 30개 대비·50,550행은 새 R 프로세스와 SQLite·CSV·Parquet 사이에서 대조했습니다.
원래 경로 결과를 보존하며 새 출력 버전 2개의 과학적 수록 판정은 대기 상태입니다.
과거 실행에서 남아 있지 않은 정확한 통계량·난수 상태까지 복구한 것은 아닙니다.
통계와 API 선택 방법은 [경로 버전 안내](PATHWAY_METHOD_VERSION_ko.md)에 있습니다.

## 설명과 재사용 자료

한국어 README를 기본으로 하고 영문 안내를 연결했습니다. DB 구조, 요구르트 예시,
집계 단위, 공개 후보와 연구실 판의 범위를 설명했습니다. 보고서용 그림은 PNG·SVG·PDF,
연결 정의 CSV와 재생성 코드로 제공합니다.

`code-files.sha256.json`은 이 코드판의 파일 해시입니다. 저장소 루트에서
`python scripts/verify_repository_files.py`로 확인할 수 있습니다.
과거 동결 코드 목록은 `docs/source-archives/`에 별도로 보존했습니다.

## 검증 범위

이번 통합의 코드 검사와 화면 빌드 결과는 [검사 기록](validation/20261024.json)에 기록합니다.
GitHub Actions의 Python 및 프런트엔드 검사는 각 commit을 대상으로 다시 실행합니다.
작은 시험 자료의 검사, 실제 데이터·브라우저 검사, 전문가의 원문 판정은 각각 다른 범위입니다.

이 코드 갱신으로 최종 운영판의 성능 재검증이나 봉인된 30개 질의의 정확도 평가가 완료되는 것은 아닙니다.
과거 warm 성능 결과를 이 통합판의 새 성능 결과로 제시하지 않습니다.
공개 데이터·버전 DOI·외부 HTTPS 서비스와 사람 검수도 진행 중입니다.

## 별도 작업

DIRECT PLUS 확장은 기존 수록 규모에 합산하지 않았습니다. 전체 QC·민감도 분석과 검수는
별도 결과판으로 관리합니다. 문헌·모델 통합의 진행 중인 브랜치와 작업 파일도 이번 코드판에
덮어쓰거나 합치지 않았습니다. 별도 검증 후 통합할 수 있습니다.
