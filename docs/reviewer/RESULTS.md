## 평가 조건과 재현

관계 존재 분류에는 정답 개체와 ID를 제공했다. 전체 자동 관계 추출은 개체·ID·유형을 모두 자동 처리한 반복 개발 100편·정답 154건 평가다. NER은 공식 학습 자료의 문헌 단위 OOF이며, 임상 평가는 자료별 개발 200편의 결과 구절 토큰이다. 영양 문헌 전문가 정확도와 완전한 군·용량·시점 연결은 별도 측정 항목이다.
