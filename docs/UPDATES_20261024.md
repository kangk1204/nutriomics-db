# Code and documentation update, 24 October 2026

[Overview](../README.en.md) · [한국어](UPDATES_20261024.ko.md) · [Status](PROJECT_STATUS.md)

The default code includes larger interface text, table/panel scrolling fixes, Korean food names
and aliases, source-backed Korean dish preparation, gene-name and identifier lookup, and
selection-state fixes that prevent old results from appearing under a new search.

Offline exports preserve their embedded scope and distinguish unavailable evidence. Explicit
GSE56960 pathway-version selection verifies parent analysis keys and artifact hashes. Feature
display types preserve native gene, probe, region and pathway identifiers. Bounded read-only
SQLite page caches and batched gene previews reduce repeated database work.

The method update covers 30 contrasts and 50,550 rows compared across a fresh R process and
SQLite/CSV/Parquet. It preserves historical values; the two new output versions await scientific
inclusion decisions. Missing historical statistics and RNG checkpoints were not recovered.

Korean and English instructions include the data structure, yogurt example, count definitions,
availability and remaining review. Figure files include PNG, SVG, PDF, source tables and code.
`code-files.sha256.json` records this version's file hashes; verify them with
`python scripts/verify_repository_files.py`. Historical source inventories remain in
`docs/source-archives/`.

See the [validation record](validation/20261024.json) and the commit-specific GitHub Actions jobs.
Code tests and a browser build do not establish expert acceptance, biological accuracy or
operational performance. Prior warm benchmarks are not reported as tests of this merged code.

The final sealed-query evaluation, human review, data deposit, version DOIs and external HTTPS
service remain pending. DIRECT PLUS extension data and ongoing literature/model integration
are separate from the reported core dataset and this code update.
