# Data licensing

Project-authored curation and project-produced quantitative analysis outputs
are offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
This applies only to records explicitly included under an affirmative
source/output policy. Cite the source study and exact dataset version.

Upstream files and facts retain their source-specific terms. See each release's
`source-catalog.json`, `rights-policy.json`, `exclusions.json`, and each result's
`rights_policy_id`. Code licensing does not sublicense source databases.
Unknown permissions and explicit record prohibitions exclude payload values.
Raw participant data and source publications are not licensed by this notice.
The NCBI GEO policy is recorded as `LicenseRef-NCBI-GEO-policy`, not relabelled
CC BY. DIRECT PLUS derived values remain excluded until its source terms have
been assessed for this specific deposited release.

A candidate release may contain scientifically unreviewed curation. A data
license permits reuse; it does not establish scientific validation or efficacy.
